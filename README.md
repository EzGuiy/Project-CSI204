## 🚀 ขอบเขตการให้บริการ (Service Scope)

ระบบของพวกเราครอบคลุมฟังก์ชันการทำงานและการรับประกันในส่วนต่าง ๆ ดังนี้:

1. **ระบบหน้าบ้าน (Frontend):** 
   * การเข้าชมและค้นหาแผงโซลาเซลล์
   * ระบบคํานวณขนาดแผงเบื้องต้นสำหรับผู้ใช้งาน
   * ระบบจัดการตระกร้าสินค้า
2. **ระบบชำระเงิน (Payment Gateway):** 
   * รองรับการตัดบัตรเครดิต
   * การสแกน QR Code (PromptPay)
   * ระบบแนบหลักฐานการโอนเงิน
3. **ระบบติดตามผลการสั่งซื้อ (Order Tracking System):** 
   * อัปเดตและแจ้งเตือนสถานะแบบเรียลไทม์: `รอชำระเงิน` -> `ตรวจสอบ` -> `กำลังจัดส่ง` -> `จัดส่งสำเร็จ`
4. **ระบบหลังบ้าน (Backend & Database):** 
   * ระบบจัดการสต็อกสินค้า (แผงโซลาเซลล์, อินเวอร์เตอร์, อุปกรณ์ยึดเจาะ)
   * ระบบจัดเก็บและจัดการข้อมูลประวัติการสั่งซื้อของลูกค้า

## 📊 ข้อตกลงระดับการให้บริการ (Service Level Agreement - SLA)

เพื่อประสิทธิภาพสูงสุดและความพร้อมในการใช้งาน ทีมงานของเราได้กำหนดตัวชี้วัดความพร้อมและการตอบสนองไว้ดังนี้:

* **ความพร้อมใช้งานของระบบ (Availability):** ระบบต้องเปิดใช้งานได้ต่อเนื่องไม่น้อยกว่า **99.5% ต่อเดือน** (รวมเวลา Maintenance ระบบ)
* **ระยะเวลาการตอบสนอง (Response Time):** ระบบต้องตอบสนองคำขอของลูกค้า**ภายใน 3 วินาที** (เช่น การกดค้นหาแผงโซลาเซลล์และแสดงผล)
* **การสำรองข้อมูล (Backup):** สำรองข้อมูลคำสั่งซื้อ ประวัติการชำระเงิน และข้อมูลลูกค้า **ทุกวัน (Daily Backup) เวลา 02:00 น.** โดยเก็บข้อมูลย้อนหลัง 30 วัน
* **ความปลอดภัยของข้อมูล (Data Security):** ข้อมูลส่วนบุคคลและการชำระเงินทั้งหมดต้องเข้ารหัสผ่านโปรโตคอล **HTTPS (SSL)** และปฏิบัติตามมาตรฐาน **PDPA** อย่างเคร่งครัด

## 🚨 ระดับความรุนแรงของปัญหา (Severity Level & Resolution Time)

กรณีเกิดข้อผิดพลาดในระบบ e-Commerce ทีมงานจะเข้าแก้ไขปัญหาตามระดับความรุนแรงและเป้าหมายเวลาดังต่อไปนี้:

| ระดับความรุนแรง | ผลกระทบ (Impact) | ตัวอย่างเหตุการณ์ในระบบโซลาเซลล์ | เป้าหมายเวลาแก้ไข (Resolution Time) |
| :--- | :--- | :--- | :--- |
| **ระดับ 1 (วิกฤต - Critical)** | ระบบล่มโดยสิ้นเชิง ใช้งานไม่ได้เลย[cite: 1] | ลูกค้าไม่สามารถกดสั่งซื้อ หรือ ระบบชำระเงินพังล่ม (จ่ายเงินไม่ได้) | **ไม่เกิน 4 ชั่วโมง* |
| **ระดับ 2 (สูง - High)** | ฟังก์ชันหลักบางส่วนใช้งานไม่ได้ | ระบบติดตามสถานะสั่งซื้อค้าง ไม่ส่งแจ้งเตือน หรือดูสถานะขนส่งไม่ได้ | **ไม่เกิน 8 ชั่วโมง** |
| **ระดับ 3 (ปานกลาง - Medium)** | ระบบใช้งานได้แต่หน่วง/มีข้อผิดพลาดบางจุด] | หน้าเว็บโหลดรูปภาพช้า หรือระบบคำนวณขนาดแผงทำงานผิดพลาดเล็กน้อย | **ไม่เกิน 24 ชั่วโมง** |
| **ระดับ 4 (ต่ำ - Low)** | ข้อเสนอแนะ / ปรับปรุงความสวยงาม | คำสะกดผิดบนหน้าเว็บ ปุ่มปรับแต่งธีม หรือต้องการปรับเปลี่ยนฟอนต์ | **ไม่เกิน 3-5 วันทำการ** |

## 🔧 แผนการบำรุงรักษา (Maintenance Plan)

แนวทางการดูแลและเสถียรภาพของระบบหลังการส่งมอบงาน:

* **Preventive Maintenance (เชิงป้องกัน):**
  * ตรวจสอบความปลอดภัยของ Patch และอัปเดตระบบความปลอดภัยฐานข้อมูลทุกๆ สิ้นเดือน
  * ทำความสะอาด Data Log ที่ไม่จำเป็นอย่างสม่ำเสมอเพื่อคงความเร็วของระบบ
* **Corrective Maintenance (เชิงแก้ไข):**
  * มีทีม Support คอย Monitor และสแตนด์บายแก้ไข Bug ตามตารางระดับความรุนแรง (Severity Level)
